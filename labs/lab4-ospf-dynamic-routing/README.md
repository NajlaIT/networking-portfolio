# Lab 4 - Multi-Router OSPF Network

## Description

This lab demonstrates dynamic routing using OSPF between three routers and three different LANs.

## Features

* Three interconnected routers
* OSPF dynamic routing protocol
* Multiple LAN networks
* End-to-end connectivity testing
* Routing table verification

## Technologies Used

* Cisco Packet Tracer
* OSPF
* IPv4 Addressing
* Routing
* Network Troubleshooting

## Result

Successfully configured OSPF to dynamically exchange routes between routers and achieved full connectivity between all networks.
